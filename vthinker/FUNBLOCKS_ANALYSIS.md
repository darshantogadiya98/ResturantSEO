## 📊 Competitive Analysis

### FunBlocks Strengths

1. **Mature Product:** Been on market longer, more polished
2. **Content Import:** Best-in-class external content integration
3. **Export Variety:** Multiple output formats
4. **Ecosystem:** Integrated with Slides, Docs, Infographics

1. **Pricing:** Can be expensive for individuals

2. **Open Architecture:** Extensible, customizable
3. **Better UX:** Simpler, cleaner interface
4. **Cost Effective:** More affordable pricing planned

## 📝 Technical Implementation Notes

### YouTube → Mind Map

```javascript
// Approach
1. Accept YouTube URL
2. Extract video ID
3. Fetch transcript (YouTube Transcript API)
4. Send to GPT: "Convert this transcript to a mind map structure"
5. Parse response into nodes
6. Auto-layout nodes on canvas
```

### URL → Mind Map

```javascript
// Approach
1. Accept URL
2. Fetch HTML content
3. Extract text (Cheerio/Puppeteer)
4. Send to GPT: "Extract main topics and create mind map"
5. Generate nodes from response
6. Display on canvas
```

### Mind Map → Slides

```javascript
// Approach
1. Analyze canvas hierarchy
2. Group nodes by levels
3. Create slide for each major branch
4. Use pptxgenjs to generate .pptx
5. Download file
```

### Mind Map → Infographic

```javascript
// Approach
1. Extract canvas data
2. Send to design template engine
3. Apply infographic theme
4. Generate SVG/PNG
5. Download
```
